My name is Kyle Hollars, I am a student studying Materials Science and Engineering at NC State University. This website is just a place to hold and organize some of my projects, including my Senior Portfolio Project for the University Honors Program, and a math communication project called "Book N" that I began working on in my senior year of high school.



Mostly, this website is an exercise in teaching myself web design skills. In high school, I programmed with Java a lot for FTC Robotics, and have played with a few other languages, but I haven't done very much web design. I am using the [Hugo](https://gohugo.io) engine to create this site, but I have written everything on this site from scratch. I did draw some inspiration from the [Terminal](https://github.com/panr/hugo-theme-terminal) theme by Radek Kozieł, though. I would like to share this theme publicly some day, but for now it is very much in-development.
